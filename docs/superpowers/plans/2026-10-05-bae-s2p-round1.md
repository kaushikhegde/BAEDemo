**Goal:** Repurpose the workspace from SA Power Networks to BAE Systems Australia: clean out the old client, write ten synthetic Source-to-Procure discovery documents describing today's on-premise Oracle world, and run the project-level stages over them.

## Review Focus

1. **One document contradicting another** (e.g. a $100,000 threshold in the Policy and $150,000 in an SOP) — the pipeline would report a false gap. Pinned by `check-docs.sh` amount audit in Task 3 and re-run in Tasks 4–6.
2. **A planted gap too subtle to find** — the "says" side and the "does" side must both be present verbatim. Pinned by the gap-evidence check in `check-docs.sh` (Task 6, final run).
3. **A persona name that drifts from the fact sheet** ("AP Clerk" instead of "Accounts Payable Officer (APO)") — breaks the project's persona naming convention for every later feature. Pinned by the forbidden-synonym check in `check-docs.sh` and by the `personas.json` role check in Task 9.
4. **A stale CLI pin after `reset --all`** — `~/.scyne/config.json` still points at the old organisation and every CLI verb fails with "The organisation pinned … no longer resolves". Pinned by the `logout` + `init` + `whoami` sequence in Task 7.
5. **An oversized or oddly-named upload** — a filename with spaces or a document over ~30 KB risks conversion or extraction trouble. Pinned by the size and filename checks in `check-docs.sh`.

- [ ] **Step 1: Write the checker (the failing test)**

`$SCRATCH/check-docs.sh`:

```bash
#!/usr/bin/env bash
# Consistency checks for the synthetic BAE documents. Exit 1 on any FAIL.
set -u
D="$(dirname "$0")/bae-docs"
BANNER='> **SYNTHETIC — illustrative document created for discovery. Not a BAE Systems record.**'
fail=0
shopt -s nullglob
docs=("$D"/[0-9][0-9]-*.md)
[ ${#docs[@]} -eq 0 ] && { echo "FAIL no documents in $D"; exit 1; }

for f in "${docs[@]}"; do
  n=$(basename "$f")
  [ "$(head -1 "$f")" = "$BANNER" ] || { echo "FAIL banner: $n"; fail=1; }
  [[ "$n" =~ ^[0-9]{2}-[A-Za-z0-9-]+\.md$ ]] || { echo "FAIL filename: $n"; fail=1; }
  sz=$(wc -c <"$f"); [ "$sz" -le 30000 ] || { echo "FAIL size $sz > 30000: $n"; fail=1; }
  grep -qiE 'ivalua|kpmg|salesforce' "$f" && { echo "FAIL forbidden platform name: $n"; fail=1; }
  hits=$(grep -nE 'Procurement Officer|Purchasing Officer|AP Clerk|Accounts Payable Clerk|Storeman|Warehouse Officer' "$f")
  [ -n "$hits" ] && { echo "$hits" | sed "s#^#FAIL forbidden role in $n:#"; fail=1; }
done

# Amounts that are not fact-sheet thresholds — printed for a human to confirm, not failed.
ALLOWED='^\$(5,000|10,000|25,000|99,999|100,000|250|500,000|999,999|1,000,000|5,000,000|10,000,000|50,000,000)$'
```
